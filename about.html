About Motion Lab

Motion Lab is an independent, static web workbench created for hands-on exploration of UI interaction physics: asymmetric open/close durations, decelerating curves, mid-flight interruption handling, and reduced-motion accessibility.

Technical Architecture

  • Zero runtime framework dependencies — pure semantic HTML, CSS custom properties, and Vanilla JavaScript.
  • 100% relative asset & route paths designed specifically for static subpath hosting (GitHub Pages).
  • Self-hosted open-source typography with zero external trackers or private backend dependencies.
