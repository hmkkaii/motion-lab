About Motion Lab

Motion Lab is an independent, zero-dependency interactive UI motion workbench and component library built for hands-on exploration of interaction physics: asymmetric open/close durations, decelerating curves, mid-flight interruption handling, and reduced-motion accessibility.

What's Inside v2.0

  • 12 Interactive Motion Studies across Surfaces, Navigation, Feedback, and Micro-Motion with dedicated parameter Workbenches.
  • 8 Original Interactive UI Components (Pulse, Orbit, Tempo, Chroma, Focus, Forge, Shelf, Relay) with manual live controls.
  • AI-Callable Discovery & Tooling: static llms.txt, llms-full.txt, registry.json, an installable Agent Skill (skills/motion-lab/SKILL.md), and zero-dependency Python 3 + Node.js stdio MCP servers for Claude Code, Cursor, Codex, and Antigravity.
  • 100% relative asset & route paths designed for static subpath hosting (GitHub Pages) with self-hosted SIL OFL 1.1 typography and zero external trackers.
