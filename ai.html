1. Claude Code

Skill + MCP

Clone the repo once, register the zero-dependency Python 3 (or Node.js) MCP server, and symlink the Agent Skill so Claude Code applies Motion Lab tokens automatically.

Clone & Add MCP (Python 3 — zero npm/pip install) 
git clone https://github.com/17860288878k-debug/motion-lab.git ~/motion-lab

# Add zero-dependency Python 3 stdio MCP server
claude mcp add motion-lab -- python3 ~/motion-lab/mcp/motion-lab-mcp.py

# Or use Node.js (>= 18) instead:
# claude mcp add motion-lab -- node ~/motion-lab/mcp/motion-lab-mcp.mjs

# Optional: install Agent Skill globally
mkdir -p ~/.claude/skills/motion-lab
cp ~/motion-lab/skills/motion-lab/SKILL.md ~/.claude/skills/motion-lab/SKILL.md

Available MCP Tools & Resources

Both mcp/motion-lab-mcp.py and mcp/motion-lab-mcp.mjs read live from registry.json (with automatic GitHub Pages fallback).

list_motions(category?)

Returns all 12 motion studies with specs, default easing curves, triggers, and Workbench URLs. Filter by Surfaces, Navigation, Feedback, or Micro-Motion.

get_motion_spec(id)

Returns complete CSS, Vanilla JS controller, tunable CSS variables, design rationale, and reduced-motion guard for any study slug.

list_components(category?)

Returns all 8 interactive UI components with triggers, motion tokens, and live preview URLs across 6 categories.

get_component_code(id)

Returns shared widget shell CSS, component CSS, and complete self-contained HTML/JS implementation for any of the 8 widgets.

get_easing_tokens()

Returns all 6 cubic-bezier curves, 7 semantic duration tokens, ready-to-paste :root CSS block, and 5 motion principles.
